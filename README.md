# 📌 Overview

Cravora is a modern and visually engaging food ordering website designed to provide users with a smooth and interactive browsing experience. The project focuses on clean UI/UX, responsive design, and advanced frontend interactions without using external frameworks.

This project includes:
- Dynamic food menu system
- Shopping cart functionality
- Authentication modal
- Dark mode support
- Search & filtering system
- Wishlist functionality
- Nutrition information display
- Responsive layouts for all devices


---

## 2️⃣ Navigate to Project Folder

```bash

```

---

## 3️⃣ Run the Project

Open the `index.html` file in your browser.

```bash

```
